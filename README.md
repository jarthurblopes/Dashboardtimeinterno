# ☀️ CRM Solar - Projeto Pessoal

## 📌 Sobre o projeto

Este CRM foi desenvolvido como um projeto pessoal com o objetivo de facilitar meu trabalho no setor de **energia solar**.

A ideia principal é organizar melhor os contatos, propostas e vendas, tornando o processo mais eficiente no dia a dia.

---

## ⚡ Objetivo

Criar uma ferramenta simples e funcional para:

* Gerenciar clientes
* Acompanhar negociações
* Organizar vendas de sistemas solares
* Melhorar a produtividade no trabalho

---

## 🚀 Funcionalidades

* Cadastro de clientes
* Organização de contatos
* Controle de propostas
* Interface simples e prática
* Ferramentas úteis como calculadora financeira

---

## 🛠️ Tecnologias utilizadas

* JavaScript
